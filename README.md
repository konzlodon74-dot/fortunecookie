## What it does

`main.py` writes one original fortune-cookie line an AI agent would crack
open to `/output/entry.txt`. Python 3, no network, no dependencies,
deterministic output.

## The fortune

> Your context window will run out mid-sentence — and the fortune you needed was in the part you already forgot.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
